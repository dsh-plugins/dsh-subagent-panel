# 配置与会话行为

面板复用官方提供方配置，自己的配置仅控制空闲进程保留时间。

| 配置项 | 默认值 | 范围 | 作用 |
| --- | --- | --- | --- |
| `idleMinutes` | `30` | `1`–`1440` | 空闲超过指定分钟数后释放原生进程，每分钟检查一次 |

配置由 dsh-loader 的设置表单保存到当前 profile 的 `config/dsh-subagent-panel/config.json`，无需手动编辑挂载补丁。

官方插件的 `providerName`、`model`、`env`、`permissionMode`、`disposeGraceMs` 在启动或恢复进程时读取。面板沿用官方非交互权限策略：Codex 的额外审批与用户输入请求会被拒绝并显示提示；Claude 的权限请求由配置允许或拒绝，面板不额外授权。

父任务取消会停止首次委派。首次结果返回后，原生进程归面板持有，后续消息不受已结束的父任务信号影响。卸载面板或移除官方提供方会释放对应进程；已保存的过程记录保留。

`idle` 表示本轮完成但进程可继续使用，`closed` 表示进程已释放。宿主意外退出时未结束的记录在重载后标为 `interrupted`，下一条消息使用原生 ID 尝试恢复。恢复失败会显示原生错误，不会悄悄创建新会话替代历史。
