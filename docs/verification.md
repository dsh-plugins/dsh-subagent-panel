# 本地验证记录

2026-11-16 在 Windows、Node.js 24.18.0、DSH 0.2.2-rc.3 的独立 `DSH_HOME` 中完成验证。

| 检查 | 结果 |
| --- | --- |
| `pnpm check` | 类型检查、8 项协议回归检查和构建通过 |
| 实际宿主加载 | 插件正常激活，无加载失败；自定义接口返回 JSON |
| 原生右侧栏 | 标题栏入口、任务列表、多个任务标签、历史记录、工具折叠和消息输入框可用 |
| 首轮任务 | Codex 与 Claude Code 均实际调用工具读取测试文件，面板显示参数、输出及最终回答 |
| 同一进程续聊 | 两者第二轮均无需再次读文件即可复述首轮标记，原生会话 ID 保持不变 |
| 释放与重启恢复 | 释放进程并重启 DSH 后，从侧栏发送第三轮消息；两者恢复原生 ID 并保留上下文 |
| 运行中追加 | Codex 通过 steer 接收追加并在同轮回答；Claude 原生队列接收追加，并在工具间以 `absorbed_mid_turn` 消费 |
| 停止 | 两者在实际等待工具运行时收到中断，轮次变为 `interrupted` |
| 停止后继续 | 两者随后正常完成新一轮，状态回到 `idle` |
| 接口鉴权 | 未认证读取返回 401；携带有效会话但跨站的写请求返回 403 |

原生运行版本为 Codex 0.153.4、Claude Agent SDK 0.3.263；dsh-loader 为 2.0.0-dev.43473963317。模型与登录沿用本机已有原生配置。Claude 的运行中追加交由原生队列调度，最终回复是否采纳指令由当前模型决定。

回归检查覆盖 UTF-8 分片、JSON 消息结构、RPC 乱序响应及断线清理、写入断管、Claude 同名并行工具、流式与最终快照去重、Codex 最终回答选择和 token 用量保留。

验证入口仅安装在独立测试实例，主会话说明为测试夹具。侧栏中的工具调用和对话结果来自真实原生进程。验证未修改现有 DSH 工作实例，未执行 npm 发布或 Git 推送。
